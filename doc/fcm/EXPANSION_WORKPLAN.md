# FCM 完整扩展实现工作记录

用户范围：实现所提供 TTS 包对应《The Ketchup Mechanism & Other Ideas》的全部扩展模块，基础版与扩展均可由人类 UI、HTTP API 和 MCP 操作。模块按开局选择，冲突组合必须拒绝。

规则依据：TTS 包内英文扩展 PDF（17 页正文）、基础规则、FAQ、实际卡面。资源检查见 `tts-audit/README.md`。禁止用贴图存在或测试通过声称规则完整。

已检查：规则书明确允许模块组合，但“艰难抉择”要求基础里程碑，不能与“新里程碑”同时启用；六人局需要新城区，5/6 人使用说客也需要额外地图。规则书大众营销员的晋升来源一句有自指排印错误，应以卡面晋升箭头/FAQ 校验。

2026-11-05 用户明确：不兼容旧版本，允许清除游玩数据；开房时选择启用哪些扩展，可多选。已移除旧引擎复制目录和版本路由层。

当前引擎 0.3.0：17 个模块均已接入，可在创建房间时选择。新里程碑与艰难抉择互斥，其余人数与新城区依赖仍由前后端校验。未保留旧引擎兼容层。

本次补齐：

- 说客组件采用 TTS 图案转录（两格/四格直路、三格弯路、四种公园），有限库存、施工箭头、路障距离、清理开放、公园加价、首次使用增加地图；地图平移保持餐厅入口、咖啡店、广告、高速出口和施工坐标一致。
- 咖啡包括培训建店/移动、范围起点、道路桥梁路线、按板块最短/最多咖啡/歧义跳过、库存及价格结算、清理丢弃、按行动顺序奖励建店。
- 乡村包括四块永久巨型广告、四个边位、三枚高速出口、飞机互斥、无限需求、最后消费及替代食品组合。
- 新里程碑替换基础里程碑，17 个实际使用/销售/建设触发及效果；额外广告、双商品飞机、食品工资、免强制裁员、工作员工同色培训、永久邮箱、披萨电台中断选择、回合移除。
- UI 新操作表单与地图覆盖层；MCP 按房间筛选规则，并在各模块规则中返回对应 API 操作说明。奖励使用 `bonus` 阶段的合法选址列表，人类与 agent 使用同一接口。

验证记录见测试文件 `tests/test_fcm_expansion_full.py`、`tests/test_fcm_modules.py`、`tests/test_mcp.py` 与 `human-ui/tests/expansions.test.mjs`。分别检查新里程碑和艰难抉择下的最大兼容六人组合对局及确定性回放。测试不代表穷举全部地图/组合或官方认证；真实浏览器与 TCP 联调在当前受限执行环境未验证。

最终后端验证：104 项测试，4 项环境限制跳过；其余全部通过。前端补充了同回合工作员工晋升后新能力表单的回归检查。
